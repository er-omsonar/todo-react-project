# 📝 Todo Vite React Project

This is a **Todo App** built using **Vite + React**.  
It allows you to **add**, **edit**, **mark as completed**, and **delete** tasks — all while saving your data in **localStorage** so that your tasks remain even after refreshing the page.

The project also uses the **React Context API** to manage global state efficiently across components.

---

## 🚀 Live Demo
👉 [Todo Vite React Project](https://todo-vitereactproject.netlify.app/)

---

## ✨ Features

- ➕ **Add Tasks** — Create new tasks instantly.  
- 🖊️ **Edit Tasks** — Update existing tasks easily.  
- ✅ **Mark as Completed** — Check or uncheck tasks to track your progress.  
- ❌ **Delete Tasks** — Remove tasks using the delete icon.  
- 💾 **Persistent Storage** — All tasks are stored in **localStorage** until deleted.  
- ⚙️ **Context API** — Used for managing and sharing state between components globally.  
- ⚡ **Fast & Lightweight** — Powered by **Vite** for superfast builds and reloads.
